# 主题定制说明

## 白天模式

- 背景 `#FFFFFF`，侧栏 `#F6F8FA`，强调色 GitHub 蓝 `#0969DA`
- 正文 GitHub Light 风格，表格斑马纹，引用块左侧蓝条

## 黑夜模式

- 背景 `#0D1117`，侧栏 `#161B22`，强调色 `#4493F8`
- 代码块 `#161B22` 深灰底，护眼且对比度达标

## 设计参考

本阅读器的交互对标以下行业最佳实践：

- **VS Code**：资源管理器式目录树 + 面包屑 + 状态栏
- **Typora / MarkText**：所见即所得的排版密度与代码复制按钮
- **GitHub**：Markdown 渲染样式与日夜配色
- **Obsidian**：大纲导航 + 文档互链（`[xx](yy.md)` 点击直接跳转）
