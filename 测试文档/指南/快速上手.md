# 快速上手

## 打开目录的四种方式

1. **自动读取**：把 `MD阅读器.exe` 放到文档目录，双击即读当前目录及子目录。
2. **浏览选择**：点击右上角 **📂 打开目录…**（快捷键 `Ctrl+O`）。
3. **拖拽打开**：把文件夹直接拖到窗口上。
4. **命令行**：`MD阅读器.exe "D:\我的文档"`，甚至可以直接传一个 `.md` 文件路径。

## 左侧目录栏

- 📁 目录 / 📄 文件层级分明，目录后数字为该分支下的文档数。
- 🔍 搜索框按文件名实时过滤，命中分支自动展开。
- 右上角“全部展开 / 全部收起”一键互斥切换：平时显示“全部展开”，全展开后自动翻为“全部收起”。
- 文件增删改会自动刷新（防抖 800ms），也可用 `Ctrl+R` / `F5` 手动刷新。

## 右侧内容区

- 表格、任务列表、脚注、Emoji 完整渲染。
- 代码块右上角悬停出现 **复制** 按钮。
- 图片加载失败会显示友好占位而非破图图标。
- 右上角 **📑 大纲** 可按标题快速跳转。

## 快捷键一览

| 快捷键 | 作用 |
| ------ | ---- |
| `Ctrl+O` | 打开目录 |
| `Ctrl+F` | 定位到搜索框 |
| `Ctrl+R` / `F5` | 刷新 |
| `Ctrl+=` / `Ctrl+-` | 增大 / 减小字号 |
| `Ctrl+D` | 白天 / 黑夜主题切换 |
| `Ctrl+B` | 显示 / 隐藏左侧目录栏 |
