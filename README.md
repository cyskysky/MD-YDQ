# MD阅读器

简洁专业的本地 Markdown 阅读器：左边是层级目录树，右边是排版精美的阅读区。单文件、离线、双击即用。

- **阅读体验**：GitHub 风格排版，白天 / 夜晚双主题（450ms 缓动切换，原生标题栏跟随变色），代码高亮、大纲导航、目录、数学公式、图表放大预览
- **文档管理**：自动读取 exe 所在目录（含子目录）的 `.md`，文件名搜索、目录统计、打开历史、窗口/字号/目录宽记忆
- **轻量编辑**：阅读器内直接改文档，语法高亮、查找替换、排版工具栏，保存自动回到阅读模式
- **绿色便携**：所有缓存和配置写系统目录，exe 所在文件夹永远干净，放 U 盘即插即用

当前版本：**v1.0**（首版正式版）

## 系统要求

- Windows 10 1809（x64）及以上，不支持 32 位系统
- **Microsoft Edge WebView2 Runtime**（预览区依赖它渲染；Win10/Win11 多数自带）
  - 缺失时程序不会崩：目录浏览照常使用，并会弹出提示框，一键打开官方下载页
  - 官方下载：<https://go.microsoft.com/fwlink/p/?LinkId=2124703>
- 无需安装 .NET（运行时已打进 exe），无需联网（图表/公式/高亮库全部离线内嵌）

## 安装与使用

1. 拿到 `MD阅读器.exe`（约 160MB，含 .NET 运行时 + 所有离线资源库）。
2. 把 exe 放到你的 Markdown 文档目录里（或任意位置），双击运行。
3. 首次启动：
   - 默认读取 **exe 所在目录**（含子目录）下的 `.md` 文件；之后会记住你上次打开的目录
   - 也可用「打开目录…」按钮或 `Ctrl+O` 随时切换
   - 默认最大化、白天模式
4. 把程序发给别人用：直接拷这一个 exe 即可；对方机器若弹 SmartScreen「未知发布者」（程序未签名），点「更多信息 → 仍要运行」。

> 说明：程序只读你打开的目录，不扫描、不上传任何内容。

## 功能一览

### 左侧目录栏

- 只显示含有 `.md` 的分支（空目录自动剪枝），目录优先 + 字母排序，每个目录显示文档数徽标
- 文件名实时搜索过滤；全部展开 / 全部收起一键互斥切换
- 中间 22px 把手整条可拖拽调宽，拖到最窄自动吸附隐藏；收起/展开带 220ms 动画
- 人字形 `› / ⌄` 展开节点，单击即切换（无双重触发）

### 右侧阅读区

- 1080px 舒适行宽，表格自动换行不断裂；超长不换行代码块横向滚动
- 每个代码块右上角悬停出现「复制」按钮（横滚/竖滚都钉住不动）
- 外部链接自动用系统默认浏览器打开；文档内 `#锚点` 与 `.md` 互链在阅读器内跳转
- 本地相对路径图片自动内嵌显示（<3MB），缺失图片显示友好占位而非破图
- 右下角「回到顶部」按钮；打印样式已适配（隐藏按钮类元素）

### 大纲与目录

- 右侧大纲面板提取 H1–H4（含中文标题），点击平滑滚动到对应位置
- 正文支持 `[TOC]` 生成目录，同样接受 GitHub 风格别名 `[[_TOC_]]`； fences 代码块里的演示文本不会被误建目录

### 白天 / 夜晚主题

- 一键切换（顶栏按钮或 `Ctrl+D`），内容区 450ms 颜色过渡 + 程序边框 400ms 渐变同步，无闪烁
- 原生标题栏（DWM）颜色跟随主题，深色标题栏按钮在 Win10 自动回退兼容
- 夜晚配色为柔和版深色（非纯黑高对比），代码高亮同步换肤（github 亮色 ↔ github-dark-dimmed）

### Mermaid 图表

- ` ```mermaid ` 代码块自动渲染（流程图、时序图等），失败时保留源码不破版
- **点击任意图表进入放大预览**：滚轮缩放（以光标为中心）、拖拽平移、工具栏 `1:1 / 适应 / ＋ / －`、百分比显示、`Esc` 或点击遮罩关闭
- 图表主题跟随白天/黑夜重建

### 数学公式

- `$行内$` 与 `$$块级$$` 自动渲染（KaTeX 离线），颜色继承正文，日夜自动适配；无公式文档零开销

### 打开历史

- 左下角「历史」记录最近打开的 12 个目录（去重置顶），显示文档数与上次打开时间
- 单条删除 / 一键清空；已不存在的目录会标注而非报错

### 编辑模式

- 面包屑栏「编辑」按钮进入（`✏️`），编辑器带 Markdown 实时语法高亮、行号、查找条（`Ctrl+F`）、加粗/斜体/删除线/代码/链接/引用/列表/代码块/分割线/标题排版工具栏、底部行列指示
- 脏检查：有未保存更改时切换/退出会确认；`Ctrl+S` 保存（统一存为无 BOM 的 UTF-8）后自动回到阅读模式
- 状态栏中间实时显示 `词数 · 字符数 · 文件大小`

### 状态栏与字号

- 左：运行状态；中：字数统计 + `A− 字号 A+` 一体（无文档时分隔符自动隐藏）；右：`UTF-8 · 主题 · Markdown`
- 字号 `Ctrl+= / Ctrl+-`，记忆上次设置

## 支持的 Markdown 格式

基于 Markdig 0.37.0（CommonMark + GFM 全覆盖，另有 61 项渲染审计用例锁定行为）：

| 分类 | 支持内容 |
|---|---|
| 基础 | 标题（ATX/Setext，中文友好锚点）、段落、硬换行、引用（含嵌套/懒续行）、有序/无序/混合列表、分割线、转义、HTML 实体 |
| 强调 | 粗体、斜体、删除线 `~~`、高亮 `==`、插入 `++`、上下标 `^`/`~` |
| 表格 | Pipe Table（含列对齐）、Grid Table（跨行跨列）、超长单元格自动换行 |
| 代码 | 围栏/缩进代码块，**190 种语言语法高亮**（含 powershell/dockerfile/cmake 等冷门语言，未知语言自动跳过；`text`/`plaintext` 明确不着色），行内代码 |
| 任务列表 | `- [ ] / - [x]`（预览为只读展示，勾选请用编辑模式） |
| 脚注 | `[^1]` 定义与回链 |
| 扩展块 | 定义列表、缩写 `*[HTML]`、引文 `""..."`、注脚区、`{#id .class}` 通用属性、`:::` 自定义容器、figure/figcaption |
| Emoji | `:smile:` 短码 + `:)` 笑脸 |
| 链接 | 自动链接（URL/www/Email）、外部链接走系统浏览器、`.md` 文件互链、`#锚点` 跳转 |
| 图片 | 本地相对路径自动内嵌（<3MB），缺图占位；网络图片需联网加载 |
| 公式 | KaTeX 行内/块级（含 `\(` `\[` 分隔符写法） |
| 图表 | 仅 Mermaid（plantuml/graphviz 等显示为普通代码块） |
| 目录 | `[TOC]` 与 `[[_TOC_]]` |
| 告示 | GitHub 5 种 `> [!NOTE/TIP/IMPORTANT/WARNING/CAUTION]`（单段多段均可） |
| Front Matter | YAML 头部解析且不泄漏到正文 |
| 原生 HTML | 直通 Chromium 渲染：`<details>` 折叠、`<kbd>`、`<ruby>` 注音等开箱即用 |

**明确不支持**：Obsidian `[[双链]]` / `![[嵌入]]`（显示原文）、Obsidian 专有 callout 类型（退化为普通引用）、图片尺寸语法（`|300` 等显示原文）。

## 从源码构建

环境：.NET 8 SDK（`net8.0-windows10.0.17763.0` 目标，需 Windows 版 SDK 以引用 WebView2 WPF 控件）。

```powershell
# 调试构建
dotnet build MDReader\MDReader.csproj -c Release

# 发布：单文件自包含 win-x64（约 160MB，目标机无需 .NET；已剔除 WinForms/诊断冗余约 30MB）
dotnet publish MDReader\MDReader.csproj -c Release -o MDReader\publish
```

- 版本号：`MDReader\MDReader.csproj` 的 `<Version>`（标题栏自动显示）。
- 离线资源（`MDReader\Assets\`，`EmbeddedResource` 打进 exe，均按“有才注入”策略，无关文档零开销）：
  - `mermaid.min.js` v11.4.1（图表）、`katex.min.js` + `katex-auto-render.min.js` + `katex.css` v0.16.11（公式，字体已转 data URI）
  - `hljs.min.js` v11.9.0 全语言包（`highlight.core` + 192 语言拼接，见构建备注）+ `hljs-github.min.css` / `hljs-github-dark-dimmed.min.css`
  - `AppIcon.ico`（16–256 多尺寸应用图标）
- 依赖：Markdig 0.37.0、Microsoft.Web.WebView2 1.0.2957.106（NuGet 还原需联网一次）。
- `测试文档\` 下有格式冶具（`格式画廊.md` 全格式演示、`宽代码块.md` 横滚与高亮演示），可直接打开验证。

> highlight 全语言包构建备注：官方不再提供单文件 full 构建，本项目用 `highlight.core`（common 包）+ 官方 `build/languages/*.min.js`（除 common 已含 40 种，实测注册约 190 种）以 `\n;\n` 分隔拼接，末尾用 `node --check` 做语法校验。升级版本时按同样步骤重拼即可。

## 常见问题

- **预览区空白 / 弹 WebView2 缺失提示**：安装 WebView2 Runtime（见[系统要求](#系统要求)），重开即恢复；期间目录浏览不受影响。
- **SmartScreen 拦截**：未签名包的常规提示，选「更多信息 → 仍要运行」。
- **exe 有 160MB**：含 .NET 8 运行时与全部离线库，首次启动需解包到临时目录，稍慢，之后正常。
- **在 ARM / 32 位 Windows 上**：仅提供 x64 构建，32 位不可用，ARM 靠系统转译（不保证）。
- **换电脑后配置丢失**：配置在 `%AppData%`，属本机漫游范围之外，重设一次即可；文档目录本身无任何写入。
- **杀软报毒**：单文件自包含 exe 偶发误报（行业常见），将文件加入白名单或用源码自行构建。
